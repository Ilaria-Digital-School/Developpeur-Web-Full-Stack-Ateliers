# Refactoriser Factorielle en fonction

Rappel théorique. Une fonction est un bloc de code nommé, réutilisable, qui prend éventuellement des paramètres en entrée et retourne une valeur en sortie. Le mental model à garder en tête : une fonction est une « boîte » qui transforme des entrées en une sortie, sans que l'appelant ait besoin de connaître son fonctionnement interne. Refactoriser signifie réécrire un code existant pour l'améliorer (lisibilité, réutilisabilité, testabilité) sans changer son comportement observable. La factorielle d'un entier n (notée n!) est le produit de tous les entiers de 1 à n, avec la convention 0! = 1. Vous avez déjà calculé une factorielle avec une boucle : l'objectif ici est d'encapsuler ce calcul dans une fonction propre. Les erreurs fréquentes : oublier le cas de base (0! = 1), ne pas gérer les entrées invalides (nombres négatifs, non-entiers), confondre afficher (console.log/print) et retourner (return), ou encore laisser des variables globales polluer le code au lieu d'utiliser la portée locale.
