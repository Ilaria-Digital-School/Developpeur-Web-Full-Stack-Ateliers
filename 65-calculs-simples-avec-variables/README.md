# Calculs simples avec variables

**Rappel théorique** Une variable est un espace mémoire nommé qui stocke une valeur pouvant changer au cours de l'exécution d'un algorithme. On la déclare en lui attribuant un nom (identificateur), un type et éventuellement une valeur initiale. Les types courants sont : entier (nombre sans décimale), réel (nombre à virgule), chaîne de caractères (texte) et booléen (vrai/faux). Une constante, elle, est fixée une fois pour toutes et ne change jamais (ex. : PI = 3.14159). Le modèle mental à retenir : imaginez une boîte étiquetée. L'étiquette, c'est le nom de la variable ; le contenu de la boîte, c'est sa valeur. Lorsque vous effectuez un calcul, vous lisez le contenu, vous opérez, puis vous rangez le résultat dans une nouvelle boîte (ou la même). Erreurs fréquentes à éviter : confondre l'affectation (variable ← valeur) avec l'égalité mathématique ; utiliser une variable avant de l'avoir déclarée ou initialisée ; mélanger les types (additionner un entier et une chaîne, par exemple) ; oublier les priorités opératoires (multiplication avant addition). Mini-exemple : ``` CONSTANTE TVA ← 0.20 variable prixHT : réel variable prixTTC : réel prixHT ← 150.00 prixTTC ← prixHT + (prixHT * TVA) Afficher prixTTC // Résultat attendu : 180.00 ``` Ce rappel posé, vous avez tous les outils nécessaires pour aborder l'atelier. --- **Énoncé de l'atelier** Dans cet atelier, vous allez concevoir et rédiger des algorithmes en pseudo-code pour résoudre cinq problèmes de calculs concrets. Chaque problème nécessite de déclarer des variables, d'affecter des valeurs, de réaliser des opérations arithmétiques...
