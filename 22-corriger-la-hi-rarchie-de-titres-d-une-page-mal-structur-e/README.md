# Corriger la hiérarchie de titres d'une page mal structurée

Rappel théorique Une hiérarchie de titres correcte dans un document HTML n'est pas une simple convention esthétique, mais la pierre angulaire de la sémantique web et de l'accessibilité. La hiérarchie est définie par les éléments ` `, ` `, ` `. Cette structure présente un saut du niveau 1 au niveau 3, puis du niveau 3 au niveau 5. La version corrigée serait : ` `, ` `, ` `, assurant une progression logique et sans trou. Énoncé de l'atelier Vous devez analyser et corriger la hiérarchie de titres d'une page HTML mal structurée. Une page web mal codée vous est fournie. Son contenu est pertinent, mais sa structure sémantique est défaillante. Votre mission est de réviser uniquement les balises de titres pour établir une hiérarchie correcte, sans altérer le texte, les images ou le balisage non concerné. Vous allez appliquer les principes fondamentaux de la sémantique HTML que vous avez étudiés. Cet exercice pratique sollicite votre capacité à analyser un contenu, à en déduire l'organisation logique de l'information et à l'exprimer proprement en code. C'est une compétence quotidienne pour un développeur front-end et full-stack. Préparer votre analyse Commencez par prendre du recul sur le code source fourni. Ne modifiez rien dans un premier temps. Lisez attentivement tout le contenu textuel pour en comprendre le sens et les relations entre les parties. Esquissez sur papier, ou dans un document texte, un plan de la page.
