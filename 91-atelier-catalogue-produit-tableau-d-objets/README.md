# Atelier : Catalogue produit (tableau d’objets)

RAPPEL THÉORIQUE Un tableau d'objets est simplement un tableau (array) dont chaque élément est un objet littéral. C'est la structure de données la plus courante en développement web : c'est ainsi qu'on représente une liste de produits, d'utilisateurs, de commandes, etc. Le mental model à retenir : le tableau est le contenant (la collection), et chaque objet est une fiche décrivant une entité avec ses propriétés (clé: valeur). Exemple : const produits = [ { id: 1, nom: 'Clavier', prix: 45, stock: 12 }, { id: 2, nom: 'Souris', prix: 25, stock: 0 } ]; Pour exploiter ces données, on combine les méthodes de tableau vues précédemment. filter() sert à extraire un sous-ensemble (les produits en stock), map() à transformer chaque objet (récupérer uniquement les noms, ou appliquer une remise), reduce() à agréger (calculer la valeur totale du stock), et find() à retrouver un objet précis par son id. Rappel clé : filter, map et find retournent un NOUVEAU tableau ou une valeur, sans modifier l'original. Erreurs fréquentes : oublier de retourner une valeur dans le callback de map/filter (résultat rempli de undefined) ; confondre map (transforme et garde la même longueur) et filter (sélectionne et peut réduire la longueur) ; accéder à une propriété inexistante et obtenir undefined sans comprendre pourquoi ; oublier que reduce a besoin d'une valeur initiale.
