# Parcourir une liste et afficher les éléments

RAPPEL THÉORIQUE Une liste (ou tableau) est une structure de données qui stocke plusieurs valeurs dans une seule variable, chaque valeur étant accessible via un indice. Dans la majorité des langages, l'indexation commence à 0 : le premier élément est à l'indice 0, le deuxième à l'indice 1, etc. Si une liste contient N éléments, le dernier se trouve donc à l'indice N-1. Le mental model à adopter est celui d'une rangée de casiers numérotés : chaque casier contient une valeur et possède une étiquette (son indice). Parcourir une liste signifie visiter chaque élément l'un après l'autre, généralement à l'aide d'une boucle. Deux approches existent : la boucle par indice (for i de 0 à longueur-1, on accède à liste[i]) et la boucle par élément (pour chaque element dans liste). La première donne accès à la position, la seconde directement à la valeur. Erreurs fréquentes : l'erreur "hors limites" (accéder à liste[N] alors que le dernier indice est N-1), oublier d'initialiser correctement la boucle, ou confondre l'indice et la valeur. Attention aussi aux listes vides : votre code doit fonctionner même sans aucun élément. Mini-exemple (pseudo-code) : liste = [10, 20, 30] Pour i de 0 à longueur(liste)-1 faire afficher("Element " + i + " : " + liste[i]) FinPour Résultat attendu : trois lignes affichant chaque élément avec sa position.
