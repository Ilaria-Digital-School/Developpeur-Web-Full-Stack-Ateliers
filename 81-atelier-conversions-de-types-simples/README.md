# Atelier : Conversions de types simples

RAPPEL THÉORIQUE En JavaScript, chaque valeur possède un type : string (chaîne de caractères), number (nombre), boolean (vrai/faux), etc. La conversion de type consiste à transformer une valeur d'un type vers un autre. On distingue deux mécanismes. La conversion explicite (ou casting) est déclenchée par le développeur avec des fonctions comme Number(), String(), Boolean(), parseInt() ou parseFloat(). La conversion implicite (ou coercition) est effectuée automatiquement par JavaScript, notamment lors d'opérations mêlant plusieurs types. Le mental model à retenir : "JavaScript est un langage à typage dynamique et faible. Il tente de deviner ce que vous voulez, mais ses devinettes peuvent surprendre." Exemple typique : '5' + 3 donne '53' (concaténation de chaînes) alors que '5' - 3 donne 2 (soustraction numérique). L'opérateur + est ambigu car il sert à la fois d'addition et de concaténation. Les erreurs fréquentes : confondre Number('') qui renvoie 0 avec Number('abc') qui renvoie NaN ; oublier que parseInt('12px') renvoie 12 alors que Number('12px') renvoie NaN ; croire que Boolean(0) vaut true (il vaut false, car 0 est une valeur "falsy", tout comme '', null, undefined et NaN).
