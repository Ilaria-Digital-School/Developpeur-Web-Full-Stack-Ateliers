# Atelier : gérer une liste de tâches en console

RAPPEL THÉORIQUE Un tableau (array) en JavaScript est une structure ordonnée qui contient plusieurs valeurs accessibles par leur indice, en commençant à 0. Le mental model utile : imaginez une rangée de casiers numérotés. `taches[0]` désigne le premier casier. Pour manipuler ces casiers, ES6 propose des méthodes clés : `push()` ajoute un élément à la fin, `splice()` retire un élément à un indice donné, `forEach()` parcourt chaque élément, et la propriété `length` donne le nombre total d'éléments. Une fonction encapsule une action réutilisable : `function ajouter(t) { taches.push(t); }`. Les erreurs fréquentes chez le débutant : confondre l'indice et la position affichée à l'humain (le casier 0 est la tâche numéro 1), oublier que `splice(index, 1)` supprime bien 1 élément à partir de l'indice, et modifier un tableau pendant qu'on le parcourt. Attention aussi à `console.log` : il sert à afficher, pas à transformer les données. Mini-exemple : ```js let taches = []; taches.push("Apprendre les tableaux"); taches.push("Faire l'atelier"); taches.forEach((t, i) => console.log(`${i + 1}. ${t}`)); taches.splice(0, 1); // supprime la première tâche console.log(taches.length); // 1 ``` Ce rappel fait le pont entre les tableaux ES6 vus précédemment et l'application concrète de cet atelier.
