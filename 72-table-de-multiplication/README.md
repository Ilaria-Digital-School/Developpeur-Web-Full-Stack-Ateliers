# Table de multiplication

RAPPEL THÉORIQUE Une boucle permet de répéter une série d'instructions un certain nombre de fois sans réécrire le même code. Vous avez vu deux formes principales : la boucle 'for', idéale quand on connaît à l'avance le nombre d'itérations, et la boucle 'while', utile quand on répète tant qu'une condition reste vraie. Le mental model à garder en tête : une boucle possède un point de départ, une condition d'arrêt et un pas de progression. Si l'un de ces trois éléments est mal défini, la boucle peut s'exécuter à l'infini ou ne jamais démarrer. Une table de multiplication est simplement une répétition de calculs : pour un nombre N, on affiche N×1, N×2, ... jusqu'à N×10. C'est un cas d'école parfait pour manipuler les boucles et, dans sa version avancée, les boucles imbriquées (une boucle dans une boucle) pour afficher plusieurs tables d'un coup. Erreurs fréquentes : oublier d'incrémenter le compteur (boucle infinie), démarrer la boucle à 0 au lieu de 1, ou se tromper dans la borne supérieure (afficher jusqu'à 9 au lieu de 10). Attention aussi à ne pas confondre l'indice de boucle avec le résultat du calcul. Mini-exemple (pseudo-code) : pour i de 1 à 10 faire afficher 7 x i = (7 * i) fin pour Ce petit bloc affiche la table de 7.
