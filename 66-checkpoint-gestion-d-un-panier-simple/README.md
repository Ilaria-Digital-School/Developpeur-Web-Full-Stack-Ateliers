# Checkpoint - Gestion d'un panier simple

## Présentation du projet Ce checkpoint est un mini-projet de synthèse qui clôture la première partie du chapitre 'Algorithmique et logique de programmation'. Il mobilise l'ensemble des compétences acquises jusqu'ici : déclaration et affectation de variables, manipulation des types de données (entier, réel, chaîne, booléen), constantes, conventions de nommage, calculs simples et séquences d'instructions. L'objectif est de modéliser algorithmiquement la gestion d'un panier d'achat simple, sans interface graphique ni base de données. Vous travaillerez uniquement avec des variables, des constantes, des calculs et une séquence logique d'instructions. ## Contexte métier Vous êtes développeur junior dans une startup e-commerce. On vous demande de prototyper la logique de calcul d'un panier d'achat avant de l'intégrer dans une vraie application. Ce prototype prend la forme d'un algorithme (en pseudo-code ou dans un langage au choix : Python, JavaScript ou autre) qui simule les opérations de base d'un panier : ajout d'articles, calcul du sous-total, application d'une remise et calcul du total TTC. ## Périmètre fonctionnel Le panier devra gérer les éléments suivants : - **3 articles fixes** (nom, prix unitaire HT, quantité) définis comme variables ou constantes au début du programme. - **Un taux de TVA** défini comme constante (ex. : 20 %). - **Un seuil de remise** défini comme constante (ex. : si le sous-total HT dépasse 50 €, une remise de 10 % est appliquée). - **Calcul du sous-total HT** : somme des (prix unitaire × quantité) pour chaque article. - **Application conditionnelle d'une remise** : booléen indiquant si la remise...
