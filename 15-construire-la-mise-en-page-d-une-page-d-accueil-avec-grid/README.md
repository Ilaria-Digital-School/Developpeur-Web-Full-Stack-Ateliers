# Construire la mise en page d'une page d'accueil avec Grid

Mise en contexte et rappel théorique Avant de commencer la construction pratique, il est crucial de bien comprendre les concepts fondamentaux de CSS Grid Layout. Grid est un modèle de mise en page bidimensionnel conçu pour organiser le contenu en lignes et en colonnes. Contrairement à Flexbox, qui est principalement unidimensionnel, Grid vous permet de contrôler simultanément les deux axes, ce qui en fait un outil idéal pour les mises en page complexes comme les pages d'accueil. Le modèle mental central est celui d'une grille conteneur, définie par `display: grid;`, à l'intérieur de laquelle les éléments enfants sont placés dans les cellules définies. Vous contrôlez la structure via les propriétés `grid-template-columns` et `grid-template-rows`. Une erreur fréquente est de confondre les lignes et les pistes (la zone entre deux lignes) ou de mal utiliser les unités comme `fr` (fraction) qui distribuent l'espace disponible. Une autre erreur courante consiste à ne pas nommer les zones de la grille avec `grid-template-areas`, ce qui peut rendre le code moins lisible et plus difficile à maintenir pour des mises en page complexes. Par exemple, pour créer une grille de 3 colonnes avec une zone latérale, un contenu principal et un pied de page, vous pourriez définir : `grid-template-columns: 250px 1fr 250px;` et `grid-template-rows: auto 1fr auto;`.
