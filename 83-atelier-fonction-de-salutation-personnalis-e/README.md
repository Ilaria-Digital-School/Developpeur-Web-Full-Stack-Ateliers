# Atelier : fonction de salutation personnalisée

RAPPEL THÉORIQUE En JavaScript ES6, une fonction est un bloc de code réutilisable qui prend éventuellement des paramètres en entrée et retourne une valeur. Les fonctions fléchées (arrow functions) offrent une syntaxe concise : `const saluer = (nom) => { return 'Bonjour ' + nom; }`. Lorsqu'une fonction se limite à retourner une valeur, on peut omettre les accolades et le mot-clé `return` : `const saluer = (nom) => 'Bonjour ' + nom;`. Le mental model à retenir : une fonction est une machine. Vous lui donnez des ingrédients (les paramètres), elle exécute une recette (le corps), et elle vous rend un plat (la valeur retournée via `return`). Les template literals, écrits avec des backticks (`` ` ``), permettent d'insérer directement des variables dans une chaîne grâce à la syntaxe `${variable}`. Exemple : `` `Bonjour ${nom}, tu as ${age} ans` ``. C'est bien plus lisible que la concaténation avec `+`. Erreurs fréquentes : oublier le `return` (la fonction renvoie alors `undefined`), confondre affichage (`console.log`) et retour (`return`), utiliser des guillemets classiques au lieu de backticks pour les template literals, et oublier de gérer le cas où aucun argument n'est fourni. Mini-exemple complet : `const bienvenue = (prenom = 'invité') => `Salut ${prenom} !`;` `console.log(bienvenue('Léa')); // Salut Léa !` `console.log(bienvenue()); // Salut invité !` Ce rappel réunit tout ce que vous avez vu dans les chapitres précédents : variables, opérateurs, conditions et fonctions fléchées.
