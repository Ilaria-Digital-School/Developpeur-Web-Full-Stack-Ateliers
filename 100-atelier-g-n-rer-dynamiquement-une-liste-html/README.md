# Atelier : générer dynamiquement une liste HTML

RAPPEL THÉORIQUE Dans les chapitres précédents, tu as appris à sélectionner des éléments du DOM, à modifier leur contenu, à jouer avec classList, et surtout à créer, insérer et supprimer des nœuds. Tu as aussi manipulé des tableaux d'objets et découvert le destructuring. Cet atelier combine ces deux mondes : transformer des données JavaScript (un tableau d'objets) en éléments HTML affichés à l'écran. Le mental model à retenir : les données vivent en JavaScript (un tableau), et le DOM n'est qu'une projection visuelle de ces données. Pour générer une liste, tu parcours ton tableau (avec forEach ou map), et pour chaque élément tu crées un nœud (document.createElement), tu le remplis (textContent, classList, dataset), puis tu l'attaches au DOM (appendChild ou append). Erreurs fréquentes : utiliser innerHTML avec du contenu non maîtrisé (risque de sécurité et code fragile) ; oublier d'attacher le nœud créé au DOM (createElement seul n'affiche rien) ; recréer toute la liste sans vider l'ancienne, ce qui provoque des doublons ; confondre textContent (texte brut, sûr) et innerHTML (HTML interprété). Mini-exemple : const fruits = ['Pomme', 'Kiwi', 'Mangue']; const ul = document.querySelector('#liste'); fruits.forEach(nom => { const li = document.createElement('li'); li.textContent = nom; ul.appendChild(li); }); Ce schéma « parcourir → créer → remplir → attacher » est le cœur de tout affichage dynamique en JavaScript vanilla, et il te servira demain avec React ou n'importe quel framework.
