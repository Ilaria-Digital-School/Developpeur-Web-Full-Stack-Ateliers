# Installer Git et créer le dépôt de votre dossier de travail

Rappel théorique sur Git Git est un système de gestion de versions décentralisé. Il permet d'enregistrer l'ensemble des modifications apportées aux fichiers d'un projet au fil du temps. Cette fonctionnalité est essentielle dans le développement professionnel pour suivre l'évolution du code, collaborer sans conflits, et revenir à un état antérieur du projet en cas d'erreur. Les concepts clés sont le contrôle de version, la décentralisation, et les branches. Le modèle mental à adopter est celui des trois zones de travail de Git : le répertoire de travail (vos fichiers actuels), l'index (staging area) où vous préparez un instantané, et le dépôt (repository) local qui contient l'historique validé. Une erreur fréquente est de confondre ces zones, par exemple en pensant qu'un fichier modifié est automatiquement prêt à être enregistré dans l'historique. Une autre erreur courante est d'initialiser un dépôt Git dans le mauvais dossier, comme le répertoire personnel, ce qui peut créer une confusion importante par la suite. Un mini-exemple : si vous avez trois fichiers modifiés, vous pouvez en ajouter seulement deux dans l'index avec 'git add', puis effectuer un commit. Le troisième fichier reste dans votre répertoire de travail, non inclus dans cet instantané de l'historique. Préparation de votre environnement Cet atelier vous guide dans la mise en place d'un outil fondamental pour votre carrière de développeur. Vous allez installer Git sur votre machine et l'utiliser pour mettre sous contrôle de version le dossier de travail que vous avez déjà manipulé dans les ateliers précédents.
