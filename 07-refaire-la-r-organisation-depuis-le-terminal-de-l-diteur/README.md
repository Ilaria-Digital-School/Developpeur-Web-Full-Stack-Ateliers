# Refaire la réorganisation depuis le terminal de l'éditeur

Rappel théorique : Le terminal intégré et le système de fichiers Le terminal est un puissant outil textuel permettant d'interagir directement avec le système d'exploitation de votre ordinateur via des commandes. Dans notre contexte, le terminal intégré à l'éditeur de code vous permet d'exécuter ces commandes depuis le même environnement que celui où vous écrivez votre code, améliorant ainsi votre productivité et votre compréhension de l'espace de travail. Le modèle mental clé est celui d'un explorateur, où vous naviguez dans une arborescence de dossiers et manipulez des fichiers à l'aide de commandes textuelles précises. Contrairement à une interface graphique, vous n'avez pas de bouton "Annuler" universel pour les opérations irréversibles, ce qui nécessite une exécution réfléchie. Les définitions essentielles sont : 'pwd' pour connaître votre emplacement, 'ls' pour lister le contenu, 'cd' pour changer de dossier, 'mkdir' pour créer des dossiers, 'mv' pour déplacer/renommer et 'rm' pour supprimer. Une erreur fréquente est de s'égarer dans l'arborescence et d'exécuter une commande dans le mauvais dossier. Un exemple serait de vouloir créer un dossier 'docs' dans votre dossier utilisateur, mais d'exécuter 'mkdir docs' depuis le répertoire racine '/', ce qui créerait un dossier global plutôt que personnel. Un autre piège est la suppression de fichiers sans possibilité de récupération avec 'rm'. Un mini-exemple concret illustre cela. Supposons un dossier 'Projet_Brouillon' contenant trois fichiers : 'script1.py', 'notes.txt' et 'test.tmp'.
