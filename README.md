# Développeur Full-Stack

Devenir développeur full-stack, de zéro jusqu'au niveau licence : concevoir, développer, sécuriser, tester et déployer des applications web et mobiles. Compétences : Comprendre le fonctionnement des ordinateurs, des systèmes et des réseaux ; Programmer en JavaScript et en Python, en programmation orientée objet ; Analyser un besoin et concevoir un système (modélisation des données, maquettes, UML) ; Concevoir et interroger des bases de données SQL et NoSQL ; Développer des interfaces web accessibles avec HTML, CSS et Angular ; Développer des API REST avec Node et Express ; Sécuriser une application web ; Tester, conteneuriser et déployer en intégration continue ; Concevoir une architecture logicielle multicouche ; Administrer des réseaux et des bases de données ; Analyser des données avec Python ; Piloter un projet informatique en méthode agile ; Respecter le droit et l'éthique du numérique. Les ateliers s'appuient sur des exercices et sur les projets que vous construisez au fil du cursus, dont votre boutique en ligne ; les données nécessaires sont fournies.

[Voir l'atelier complet](https://www.ilaria-academy.com/nextjob/full-stack-web-developer/fr/)
