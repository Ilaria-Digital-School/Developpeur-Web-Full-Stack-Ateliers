# Atelier : Compteur de clics (prompt)

RAPPEL THÉORIQUE En JavaScript, une variable déclarée avec 'let' peut être modifiée après sa création, contrairement à 'const' qui reste constante. Pour un compteur, on utilise donc 'let compteur = 0;' car sa valeur va évoluer. La fonction native 'prompt()' affiche une boîte de dialogue qui interrompt le programme et attend une saisie de l'utilisateur : elle retourne toujours une chaîne de caractères (string), ou 'null' si l'utilisateur annule. C'est un point crucial : si vous voulez faire des calculs, vous devez convertir le texte en nombre avec 'Number()' ou 'parseInt()'. Le mental model à retenir : un compteur, c'est une valeur en mémoire que l'on incrémente (compteur++) ou décrémente (compteur--) à chaque action. Une boucle (par exemple 'while' ou 'for') répète une instruction tant qu'une condition est vraie. Ici, on répète la demande à l'utilisateur tant qu'il n'a pas décidé d'arrêter. Erreurs fréquentes : oublier que 'prompt()' renvoie une chaîne (donc '5' + 1 donne '51' et non 6) ; créer une boucle infinie sans condition de sortie ; comparer avec '==' au lieu de '===' (comparaison stricte recommandée). Mini-exemple : let compteur = 0; let reponse = prompt('Tapez CLIC pour compter, STOP pour arrêter'); while (reponse !== 'STOP') { compteur++; console.log('Nombre de clics : ' + compteur); reponse = prompt('CLIC ou STOP ?'); } console.log('Total final : ' + compteur); Ce rappel réutilise vos acquis sur les variables, les conditions et vos premières fonctions. --- ÉNONCÉ DE L'ATELIER Vous allez construire un petit programme JavaScript simulant un compteur...
