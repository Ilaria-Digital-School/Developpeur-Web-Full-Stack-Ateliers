# Repérer balises, éléments et attributs dans un extrait de code

Rappel théorique : les fondements du HTML Le langage HTML est le squelette de toute page web. Il doit être écrit selon des règles syntaxiques précises que les navigateurs décodent pour afficher le contenu. Ce rappel réactive vos connaissances avant l'atelier pratique. Une balise est un mot-clé entouré de chevrons, comme `` ou ``. Elle sert de marqueur pour indiquer au navigateur où commence et où se termine un type de contenu. Une balise ouvrante ouvre une section, une balise fermante la clôt. Toutes les balises doivent être correctement fermées sauf quelques exceptions dites auto-fermantes. Un élément HTML est la structure complète, englobant la balise ouvrante, le contenu et la balise fermante. Par exemple, ` ` constitue un élément titre. Le mental model à adopter est celui d'un système d'emboîtement, ou d'imbrication : des éléments conteneurs englobent des éléments enfants à l'intérieur d'eux, formant une arborescence logique. Un attribut fournit des informations supplémentaires à une balise ouvrante pour modifier son comportement ou son apparence. Les attributs sont toujours placés dans la balise ouvrante sous la forme `nom="valeur"`. Par exemple, `Lien` utilise l'attribut `href` pour définir l'adresse cible du lien. Une erreur fréquente consiste à confondre attributs et balises, ou à mal fermer les éléments, ce qui peut rompre la structure de la page.
