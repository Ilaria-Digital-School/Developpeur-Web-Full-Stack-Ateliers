# Atelier : calculatrice refactorisée avec fonctions

RAPPEL THÉORIQUE Une fonction est un bloc de code réutilisable qui accomplit une tâche précise. En JavaScript ES6, on peut la déclarer de façon classique (function additionner(a, b) { return a + b; }) ou sous forme de fonction fléchée (const additionner = (a, b) => a + b;). Le mental model à retenir : une fonction reçoit des entrées (paramètres), effectue un traitement, puis renvoie une sortie via return. Une fonction sans return renvoie undefined. Le principe clé de cet atelier est la refactorisation : réorganiser un code existant sans changer son comportement, mais en le rendant plus lisible, plus modulaire et plus maintenable. Au lieu d'écrire tout le code de calcul « en vrac », on isole chaque opération dans sa propre fonction. Ce découpage suit le principe de responsabilité unique : une fonction = une tâche. Erreurs fréquentes : oublier le return (la fonction ne renvoie rien), confondre afficher (console.log) et retourner (return), ne pas gérer la division par zéro, ou répéter du code au lieu de le factoriser. Attention aussi aux comparaisons : utilisez === et non ==. Mini-exemple : const multiplier = (a, b) => a * b; const resultat = multiplier(4, 5); // 20 console.log(`Résultat : ${resultat}`); Ici, la fonction calcule et renvoie, l'affichage se fait séparément avec un template literal.
