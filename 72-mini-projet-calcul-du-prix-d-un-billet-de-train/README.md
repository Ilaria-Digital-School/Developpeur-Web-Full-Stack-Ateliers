# Mini-projet - Calcul du prix d'un billet de train

Rappel théorique : Une condition permet à un programme de prendre une décision et d'exécuter des instructions différentes selon les situations. Le mental model à retenir est simple : « SI une expression est vraie ALORS je fais ceci, SINON je fais cela ». Les expressions conditionnelles reposent sur des opérateurs de comparaison (==, !=, , =) qui renvoient un booléen (true ou false), et sur des opérateurs logiques (AND, OR, NOT) qui permettent de combiner plusieurs tests. En JavaScript, cela se traduit par les structures if, else if et else. Les erreurs fréquentes des débutants sont : confondre l'affectation (=) avec la comparaison (==/===), oublier que l'ordre des conditions dans un enchaînement if/else if compte (la première condition vraie est exécutée et les suivantes ignorées), et mal combiner AND et OR sans parenthèses, ce qui produit une logique inattendue. Un dernier piège classique est de tester une valeur en dehors des bornes attendues (par exemple un âge négatif) sans prévoir de garde-fou. Mini-exemple : imaginons un tarif dépendant de l'âge. « SI l'âge est inférieur à 12 ALORS tarif enfant, SINON SI l'âge est supérieur ou égal à 65 ALORS tarif senior, SINON tarif adulte ». En pseudo-code : if (age < 12) { prix = 5; } else if (age >= 65) { prix = 8; } else { prix = 12; }. On voit ici que l'ordre garantit qu'un enfant ne tombe jamais dans la catégorie adulte. Ce raisonnement par cas est exactement celui que vous allez...
