# Réorganiser un dossier uniquement avec le terminal

Rappel théorique pour l'action Le terminal, ou interface en ligne de commande (CLI), est un outil fondamental permettant de piloter un ordinateur via des instructions textuelles. Pour un développeur, maîtriser cet outil est essentiel pour naviguer dans le système de fichiers, manipuler des dossiers et des fichiers, et automatiser des tâches. Le modèle mental clé est celui d'une arborescence de dossiers, où vous vous déplacez en tant qu'utilisateur à l'aide de commandes spécifiques. Les erreurs fréquentes incluent l'exécution de commandes sans vérifier le répertoire courant, l'utilisation de chemins relatifs erronés, et l'oubli des options de sécurité comme `-i` pour les opérations de suppression. Les commandes de base que vous avez déjà rencontrées sont `pwd` (afficher le répertoire actuel), `ls` (lister le contenu), `cd` (changer de répertoire), `mkdir` (créer un dossier), `cp` (copier), `mv` (déplacer ou renommer), et `rm` (supprimer). Un exemple concret serait de créer un dossier `backup` dans votre répertoire personnel et d'y déplacer un fichier `rapport.txt` : vous utiliseriez `mkdir backup` puis `mv rapport.txt backup/`. Ce rappel sert de pont vers l'atelier pratique, où vous devrez appliquer ces commandes de manière combinée et logique pour résoudre un problème d'organisation concret. Comprendre la mission Vous allez recevoir un dossier nommé `messy_project`. Ce dossier contient des dizaines de fichiers de différents types (fichiers de code, images, documents, fichiers de configuration) tous mélangés à la racine. Votre mission est de restructurer cette arborescence de manière propre et professionnelle en utilisant exclusivement le terminal. Vous ne devez pas utiliser l'explorateur de fichiers...
