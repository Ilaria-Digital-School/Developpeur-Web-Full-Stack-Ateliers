# Atelier : filtrer et transformer une liste de produits

RAPPEL THÉORIQUE En JavaScript ES6, les méthodes de tableau map, filter et reduce sont des outils fondamentaux pour manipuler des collections de données sans écrire de boucles manuelles. Le mental model à retenir : ces méthodes ne modifient pas le tableau d'origine (elles sont dites non destructives), elles retournent un nouveau tableau (ou une valeur pour reduce). filter() garde uniquement les éléments qui satisfont une condition (le callback retourne true ou false). map() transforme chaque élément et retourne un tableau de même longueur. reduce() agrège tous les éléments en une seule valeur (somme, moyenne, objet…). Les erreurs fréquentes à éviter : oublier de retourner une valeur dans le callback de map ou filter (résultat rempli de undefined) ; confondre filter et map (filter sélectionne, map transforme) ; tenter de modifier le tableau original alors qu'on devrait travailler sur le résultat retourné ; oublier la valeur initiale de reduce, ce qui provoque des bugs sur un tableau vide. Mini-exemple : const produits = [{ nom: 'Clavier', prix: 40 }, { nom: 'Souris', prix: 20 }]; const chers = produits.filter(p => p.prix > 30); // [{ nom: 'Clavier', prix: 40 }] const noms = produits.map(p => p.nom); // ['Clavier', 'Souris'] const total = produits.reduce((acc, p) => acc + p.prix, 0); // 60 Ces trois méthodes se chaînent naturellement (filter puis map puis reduce), ce qui rend le code lisible et déclaratif.
