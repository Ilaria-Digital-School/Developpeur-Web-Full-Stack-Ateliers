# Créer une fonction somme

RAPPEL THÉORIQUE Une fonction est un bloc de code nommé, réutilisable, qui prend des données en entrée (les paramètres), effectue un traitement, puis renvoie un résultat grâce à une instruction de retour (return). Le mental model à garder en tête est celui d'une machine : vous lui donnez des ingrédients (arguments), elle exécute une recette (le corps de la fonction) et vous rend un plat (la valeur retournée). L'intérêt majeur est la modularité : au lieu de réécrire le même calcul partout, vous l'isolez une fois et vous l'appelez autant de fois que nécessaire. Les erreurs fréquentes chez les débutants sont : oublier le return (la fonction affiche mais ne renvoie rien d'exploitable), confondre print et return, mal gérer la portée des variables (une variable interne n'existe pas en dehors de la fonction), et ne pas traiter les cas limites (liste vide, valeur non numérique). Mini-exemple en Python : def somme(a, b): return a + b resultat = somme(3, 5) # resultat vaut 8 Cette fonction prend deux paramètres, renvoie leur addition, et son résultat est stocké dans une variable. Vous avez déjà manipulé des boucles et des conditions dans les activités précédentes : ici vous allez combiner ces briques avec la notion de fonction pour produire un composant propre et réutilisable. ÉNONCÉ DU WORKSHOP Votre mission est de concevoir une ou plusieurs fonctions capables d'additionner des nombres, dans une logique progressive. Vous travaillerez en Python (langage abordé dans votre cursus pour le scripting), mais vous pouvez aussi le refaire...
