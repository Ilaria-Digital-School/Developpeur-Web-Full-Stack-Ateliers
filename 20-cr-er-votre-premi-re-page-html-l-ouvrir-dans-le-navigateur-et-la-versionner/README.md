# Créer votre première page HTML, l'ouvrir dans le navigateur et la versionner

Rétablir les fondations HTML Un document HTML est le squelette d'une page web, construit avec des balises qui délimitent les éléments. Chaque page web fonctionne selon le modèle mental d'une structure hiérarchique : le document HTML, à l'intérieur duquel sont placées les sections head et body, puis les contenus à l'intérieur de celles-ci. Les balises s'ouvrent et se ferment, formant des éléments comme ` `. Les erreurs fréquentes incluent l'oubli de balises fermantes, la mauvaise imbrication des éléments, et l'absence de la déclaration DOCTYPE qui informe le navigateur sur la version du HTML utilisé. Un autre modèle mental essentiel est la distinction entre la structure sémantique, définie par le HTML, et sa présentation visuelle, gérée plus tard par le CSS. Vous pouvez choisir une liste à puces (non ordonnée) avec `` ou une liste numérotée (ordonnée) avec ``. À l'intérieur, ajoutez au moins trois éléments de liste avec la balise ``.
