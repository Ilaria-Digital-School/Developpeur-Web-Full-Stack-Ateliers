# Naviguer dans votre dossier de travail depuis le terminal

Rappel théorique : Les bases de la navigation en ligne de commande Un terminal, aussi appelé console ou ligne de commande, est une interface textuelle permettant de donner des instructions directement à votre ordinateur. Contrairement à une interface graphique où vous cliquez sur des icônes, vous tapez des commandes qui sont exécutées immédiatement. Pour un développeur, maîtriser le terminal est fondamental car il offre un contrôle précis, est automatisable et est omniprésent sur les serveurs où les applications sont déployées. Le modèle mental clé est celui de l'arborescence. Imaginez votre système de fichiers comme un arbre à l'envers. La racine, notée `/` sur Linux/macOS ou `C:\` sur Windows, est le point de départ. De là, partent des branches (les dossiers) et des feuilles (les fichiers). Vous êtes toujours situé quelque part dans cet arbre, dans un « répertoire de travail courant ». La navigation consiste à connaître votre position, à voir ce qui vous entoure et à vous déplacer. Les trois commandes essentielles sont `pwd`, `ls` et `cd`. `pwd` (Print Working Directory) affiche le chemin complet de votre dossier actuel. `ls` (List) montre le contenu du dossier courant. `cd` (Change Directory) vous permet de vous déplacer vers un autre dossier. Une erreur fréquente est de ne pas vérifier où l'on se trouve avant d'agir, ce qui conduit à exécuter des commandes au mauvais endroit. Une autre est de mal interpréter les chemins relatifs (comme `dossier1/sous-dossier`) et absolus (comme `/home/utilisateur/projet`). Mini-exemple : vous ouvrez un terminal. Tapez `pwd`. Il affiche `/home/votre_nom`....
