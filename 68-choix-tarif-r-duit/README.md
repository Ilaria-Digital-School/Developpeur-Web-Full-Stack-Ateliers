# Choix tarif réduit

Rappel théorique : Les structures conditionnelles permettent à un programme de prendre des décisions en fonction de données. Le mental model est simple : "SI une condition est vraie, ALORS j'exécute ce bloc, SINON j'exécute un autre bloc". La condition est une expression booléenne qui vaut vrai (true) ou faux (false), construite à l'aide d'opérateurs de comparaison (==, !=, , =) et d'opérateurs logiques (ET/&&, OU/||, NON/!). Lorsque plusieurs cas s'enchaînent, on utilise SINON SI (else if) pour tester des alternatives successives. Attention à l'ordre des conditions : dès qu'une condition est vraie, les suivantes ne sont pas évaluées. Les erreurs fréquentes sont nombreuses. On confond l'affectation (=) avec la comparaison (==) ; on oublie de couvrir tous les cas, laissant certains scénarios sans réponse ; on empile des conditions dans le mauvais ordre, ce qui rend certains blocs inatteignables ; enfin, on mélange à tort le ET et le OU. Un bon réflexe : lister tous les cas possibles avant de coder, puis vérifier qu'aucun ne manque et qu'aucun ne se chevauche. Mini-exemple : pour déterminer si une personne bénéficie d'un tarif réduit, on peut écrire : SI age < 12 ALORS tarif = 5 ; SINON SI age >= 65 ALORS tarif = 7 ; SINON tarif = 10. Chaque cas est mutuellement exclusif et couvre l'ensemble des âges possibles.
