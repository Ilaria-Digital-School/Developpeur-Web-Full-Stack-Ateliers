# Atelier : sélectionner un élément et changer son texte

RAPPEL THÉORIQUE Le DOM (Document Object Model) est la représentation en mémoire de ta page HTML sous forme d'arbre de nœuds. JavaScript peut lire et modifier cet arbre grâce à l'objet global 'document'. Pour agir sur un élément, tu dois d'abord le sélectionner, puis le modifier. Le mental model est simple : « je cible, puis j'agis ». Pour sélectionner, tu disposes principalement de 'document.getElementById("id")' qui renvoie un élément unique, et de 'document.querySelector("selecteur")' qui accepte n'importe quel sélecteur CSS et renvoie le premier élément correspondant. Pour changer le texte affiché, tu utilises la propriété 'textContent' (texte brut, sûr et recommandé) ou 'innerHTML' (interprète le HTML, à utiliser avec prudence). Mini-exemple : ```js const titre = document.querySelector('#titre'); titre.textContent = 'Bonjour le DOM !'; ``` Erreurs fréquentes à éviter : (1) exécuter le script avant le chargement du HTML, ce qui renvoie 'null' — place ton juste avant la fermeture de ou utilise l'événement 'DOMContentLoaded' ; (2) confondre le sélecteur (ex. '#id' pour un id, '.classe' pour une classe) ; (3) oublier que 'querySelector' ne renvoie que le PREMIER élément ; (4) tenter de modifier un élément stocké dans une variable 'null'. Un simple 'console.log(monElement)' te permet de vérifier que la sélection a réussi. ÉNONCÉ DE L'ATELIER Tu vas construire une mini-page interactive qui met en pratique la sélection d'éléments et la modification de leur contenu textuel. L'objectif est de manipuler concrètement le DOM que tu viens de découvrir dans le chapitre précédent, en passant du concept théorique à un code fonctionnel...
