# Atelier : statistiques de notes d’élèves

RAPPEL THÉORIQUE En JavaScript ES6+, un tableau (array) permet de stocker une collection ordonnée de valeurs. On le crée avec des crochets : const notes = [12, 8, 15, 17, 6]. Chaque élément est accessible par son indice, en commençant à zéro : notes[0] vaut 12. La propriété notes.length donne le nombre d'éléments. Pour parcourir un tableau, vous disposez de plusieurs outils : la boucle classique for, la méthode forEach (parcours simple), et surtout reduce, très utile pour calculer une somme. Par exemple : const somme = notes.reduce((total, valeur) => total + valeur, 0). D'autres méthodes ES6 sont précieuses : filter (garder certaines valeurs), map (transformer chaque valeur), Math.min et Math.max (extremums), Math.round (arrondi). Mental model : imaginez un tableau comme une rangée de casiers numérotés. Vous pouvez lire chaque casier, compter combien il y en a, ou passer devant tous pour additionner leur contenu. Erreurs fréquentes : oublier que le premier indice est 0 (le dernier élément est donc notes[notes.length - 1]), diviser par notes.length égal à zéro (division par zéro = NaN ou Infinity), ou confondre le nom de variable et sa valeur. Autre piège : ne pas initialiser l'accumulateur de reduce. Mini-exemple d'une moyenne : const moyenne = notes.reduce((t, n) => t + n, 0) / notes.length.
