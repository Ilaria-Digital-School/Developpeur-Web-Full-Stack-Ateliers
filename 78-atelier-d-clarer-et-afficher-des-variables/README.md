# Atelier : déclarer et afficher des variables

Rappel théorique En JavaScript ES6, une variable est un conteneur nommé qui stocke une valeur en mémoire. On déclare une variable avec deux mots-clés principaux : 'let' pour une valeur qui pourra changer, et 'const' pour une valeur constante qui ne sera jamais réaffectée. Le mot-clé 'var', hérité de l'ancien JavaScript, est à éviter car sa portée (scope) est source de bugs. Le bon mental model est le suivant : 'const' par défaut, et 'let' uniquement quand vous savez que la valeur devra évoluer. Les valeurs manipulées ont un type primitif : string (chaîne de caractères entre guillemets), number (nombre entier ou décimal, sans distinction), boolean (true/false), null, undefined. Pour afficher une valeur pendant le développement, on utilise 'console.log()', qui écrit dans la console du navigateur ou de Node. Erreurs fréquentes : réaffecter une const (déclenche une TypeError), oublier les guillemets pour une string, confondre l'assignation '=' avec la comparaison '===', ou nommer une variable de façon peu explicite. Mini-exemple : const prenom = "Sarah"; let age = 29; age = 30; console.log(prenom, age); // affiche : Sarah 30 Ce rappel fait le pont entre le cours 'Variables ES6 et types primitifs' et l'atelier : vous allez maintenant mettre en pratique ces notions dans un vrai fichier de code.
