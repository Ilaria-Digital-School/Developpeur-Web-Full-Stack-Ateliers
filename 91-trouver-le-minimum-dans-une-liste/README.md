# Trouver le minimum dans une liste

RAPPEL THÉORIQUE Trouver le minimum dans une liste consiste à parcourir l'ensemble des valeurs et à conserver, au fur et à mesure, la plus petite rencontrée. Le modèle mental est simple : imaginez que vous tenez dans votre main une valeur "candidate" au titre de minimum. Vous comparez cette candidate à chaque élément de la liste ; dès qu'un élément est plus petit, il devient la nouvelle candidate. À la fin du parcours, votre candidate est le minimum réel. Le point crucial est l'initialisation. Une erreur fréquente consiste à initialiser le minimum à 0 : si tous les éléments sont positifs, cela fonctionne par hasard, mais si la liste contient uniquement des valeurs supérieures à 0 ou uniquement des valeurs négatives, le résultat sera faux. La bonne pratique est d'initialiser le minimum avec le premier élément de la liste (liste[0]), puis de comparer à partir du second élément. Autre erreur classique : oublier de gérer la liste vide, qui n'a pas de minimum. Mini-exemple avec [7, 3, 9, 2, 5] : on initialise min = 7. On compare 3 < 7 → min = 3. Puis 9 < 3 ? Non. Puis 2 < 3 ? Oui → min = 2. Puis 5 < 2 ? Non. Résultat : 2. Ce même schéma "initialiser puis comparer" est réutilisable pour trouver le maximum, la somme ou la moyenne : c'est un patron fondamental de l'algorithmique.
