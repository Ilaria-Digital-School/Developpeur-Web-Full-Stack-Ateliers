# Mettre en page une série de cartes avec Flexbox

Fondamentaux de Flexbox pour les cartes Flexbox est un modèle de mise en page CSS conçu pour répartir un espace entre les éléments d'un conteneur afin d'offrir des capacités d'alignement avancées. Son mental model repose sur l'idée d'un axe principal et d'un axe secondaire dans un conteneur flex. Les propriétés essentielles sont `display: flex`, `flex-direction`, `justify-content`, `align-items` et `flex-wrap`. `justify-content` gère l'espace sur l'axe principal tandis qu'`align-items` le gère sur l'axe secondaire. Une erreur fréquente est de configurer les propriétés sur les enfants sans avoir d'abord défini `display: flex` sur le parent. Une autre erreur consiste à mélanger les propriétés d'axe principal et secondaire. Voici un mini-exemple chiffré pour aligner trois cartes. Le conteneur .cartes obtient `display: flex`, `flex-wrap: wrap` et `justify-content: space-between`. Chaque enfant .carte obtient une largeur de base de `calc(33.333% - 20px)` et une marge inférieure, ce qui crée trois cartes par ligne avec espacement. Introduction au projet cartes Cet atelier vous propose de créer une page présentant une série de cartes de produits ou d'articles. Ces cartes doivent s'afficher correctement sur tous les écrans. Le rendu final doit montrer une disposition responsive utilisant uniquement Flexbox. Cette approche permet une bonne gestion de l'espace et de l'ordre des éléments selon la taille de l'écran tout en conservant un code lisible et performant. Votre travail consistera à incorporer la structure HTML de ces cartes puis à lui appliquer des styles CSS pour obtenir une mise en page dynamique et professionnelle à l'aide du modèle Flexbox.
