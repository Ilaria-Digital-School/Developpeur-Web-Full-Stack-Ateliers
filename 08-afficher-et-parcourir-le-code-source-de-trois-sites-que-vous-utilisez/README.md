# Afficher et parcourir le code source de trois sites que vous utilisez

Rappel théorique L'inspection du code source d'une page web est une compétence fondamentale pour tout développeur. Elle vous permet de comprendre comment une interface est construite, d'en analyser la structure et d'identifier les technologies employées. Le code source correspond à l'ensemble des fichiers HTML, CSS et JavaScript que le navigateur télécharge et interprète pour afficher la page que vous voyez. Le modèle mental clé est de considérer tout site web comme une application logicielle dont le code est, par nature, accessible au client. Contrairement à une idée reçue, ce code est rarement un secret industriel ; il est plutôt le résultat d'un processus de construction que vous pouvez observer et analyser. Les erreurs fréquentes pour les débutants incluent la confusion entre le code source rendu (celui modifié par le JavaScript) et le code source originel, ou encore l'analyse d'une page après des actions utilisateurs sans recharger la page depuis son état initial. Un mini-exemple concret : sur une page simple, le code HTML définit la structure (titres, paragraphes, images), le CSS apporte le style (couleurs, marges, polices) et le JavaScript ajoute l'interactivité (menus déroulants, formulaires). En utilisant les outils de développement de votre navigateur (généralement accessible par la touche F12), vous pouvez inspecter chaque élément, voir les règles CSS appliquées et observer les appels réseau. Cette pratique développe votre œil critique et votre compréhension des bonnes pratiques de développement web.
