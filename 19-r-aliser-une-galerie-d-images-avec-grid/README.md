# Réaliser une galerie d'images avec Grid

Rappel théorique sur CSS Grid CSS Grid Layout est un système de mise en page bidimensionnel conçu pour créer des interfaces web complexes. Contrairement à Flexbox qui est axé sur un flux ligne ou colonne, Grid permet un contrôle simultané sur les lignes et les colonnes. Il repose sur deux concepts centraux : le conteneur Grid (`display: grid`) et les items Grid. Le modèle mental consiste à définir une grille invisible sur le conteneur, puis à placer les éléments enfants dans ses cellules. La structure est définie par les propriétés `grid-template-rows` et `grid-template-columns`. Une erreur fréquente est de confondre Grid et Flexbox, en utilisant Grid pour aligner un seul élément ou Flexbox pour une grille complexe. Une autre erreur commune est de laisser les images définir la taille de la grille, ce qui nuit au responsive design. Un mini-exemple chiffré : un conteneur avec `grid-template-columns: repeat(3, 1fr)` crée trois colonnes de largeur égale. La propriété `1fr` (fraction) distribue l'espace disponible. Avec `grid-gap: 10px`, vous ajoutez un espacement uniforme de 10px. Ceci forme la base d'une galerie simple.
