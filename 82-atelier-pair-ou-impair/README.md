# Atelier : Pair ou impair ?

Rappel théorique : En JavaScript, déterminer si un nombre est pair ou impair repose sur l'opérateur modulo (%). Cet opérateur retourne le reste d'une division entière. Ainsi, `10 % 2` vaut 0, tandis que `7 % 2` vaut 1. Le modèle mental à retenir : un nombre est pair si le reste de sa division par 2 est égal à zéro, sinon il est impair. On combine cette logique avec une structure conditionnelle if/else et un opérateur de comparaison strict (===) : `if (nombre % 2 === 0) { ... } else { ... }`. Avant de comparer, il faut souvent convertir une saisie utilisateur en nombre, car `prompt()` retourne toujours une chaîne de caractères. Utilisez `Number(saisie)` ou `parseInt(saisie, 10)` pour éviter les mauvaises surprises. Une erreur fréquente consiste à écrire `nombre % 2 = 0` (affectation) au lieu de `nombre % 2 === 0` (comparaison). Autre piège classique : oublier la conversion et comparer une chaîne, ou ne pas vérifier que la saisie est réellement un nombre valide (attention à `NaN`). Mini-exemple : ``` const nombre = Number(prompt('Entrez un nombre :')); if (Number.isNaN(nombre)) { console.log('Ce n'est pas un nombre valide.'); } else if (nombre % 2 === 0) { console.log(nombre + ' est pair.'); } else { console.log(nombre + ' est impair.'); } ``` Ce rappel fait le lien direct avec vos cours sur les variables, les conversions de types, les opérateurs et les conditions if/else. --- Énoncé de l'atelier : Vous allez créer un petit programme JavaScript interactif...
