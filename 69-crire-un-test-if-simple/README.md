# Écrire un test IF simple

RAPPEL THÉORIQUE Un test conditionnel permet à un programme de prendre une décision. La structure de base est le fameux "IF" (SI) : SI une condition est vraie ALORS on exécute un bloc d'instructions. La condition est une expression qui vaut toujours vrai (true) ou faux (false), c'est-à-dire un booléen. On la construit avec des opérateurs de comparaison (== égal, != différent, , =) et parfois des opérateurs logiques (ET, OU, NON). Le mental model à retenir : imaginez un aiguillage. Le programme arrive à un embranchement, évalue la condition, et emprunte le chemin correspondant. Avec un IF/ELSE, on gère les deux cas (vrai et faux) ; avec un IF/ELSE IF/ELSE, on gère plusieurs cas mutuellement exclusifs. Les erreurs fréquentes chez les débutants sont : confondre l'affectation (=) avec la comparaison (==), oublier que la condition doit produire un booléen, mal imbriquer les blocs (indentation ou accolades), et tester des cas qui ne se produiront jamais. Autre piège : comparer des types différents (une chaîne "18" avec un entier 18). Mini-exemple en pseudo-code : SI age >= 18 ALORS afficher "Majeur" SINON afficher "Mineur" FIN SI. Cet exemple illustre le cœur de ce que vous allez pratiquer : évaluer une donnée, la comparer, et déclencher une action selon le résultat.
