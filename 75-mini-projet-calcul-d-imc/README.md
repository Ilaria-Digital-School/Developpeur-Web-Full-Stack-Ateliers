# Mini-projet - Calcul d'IMC

**Rappel théorique** Avant de commencer, revenons sur les concepts essentiels abordés dans les activités précédentes. Une variable est un espace mémoire nommé qui stocke une valeur pouvant évoluer au cours de l'exécution d'un programme. On distingue plusieurs types de données : les entiers (int), les réels (float), les chaînes de caractères (string) et les booléens (bool). Une constante, quant à elle, est une valeur fixe qui ne change pas durant l'exécution. Les expressions arithmétiques permettent de combiner des variables et des valeurs via des opérateurs (+, -, *, /) pour produire un résultat. L'affectation consiste à assigner une valeur à une variable avec l'opérateur =. Un mental model utile : pensez à une variable comme à une boîte étiquetée. Vous choisissez le nom de l'étiquette (convention snake_case recommandée), vous y déposez une valeur d'un certain type, et vous pouvez la relire ou la modifier à tout moment. Erreurs fréquentes à éviter : confondre l'affectation (=) et la comparaison (==), utiliser un nom de variable avec des espaces ou commençant par un chiffre, oublier de convertir une saisie utilisateur (qui est toujours une chaîne) en nombre avant d'effectuer un calcul.
