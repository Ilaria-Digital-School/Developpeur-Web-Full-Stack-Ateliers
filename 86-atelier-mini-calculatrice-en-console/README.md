# Atelier : mini-calculatrice en console

RAPPEL THÉORIQUE Avant de commencer, remettons en place les briques que tu vas utiliser. En JavaScript ES6, tu déclares tes valeurs avec 'let' (valeur qui peut changer) et 'const' (valeur qui ne change pas). Les types primitifs essentiels ici sont le 'number' (nombres) et le 'string' (texte). Attention : toute saisie utilisateur (via prompt en navigateur ou readline en Node) arrive sous forme de chaîne de caractères. Tu dois donc convertir explicitement avec Number(), parseInt() ou parseFloat() avant de calculer. Une erreur fréquente est d'oublier cette conversion : '2' + '3' donne '23' (concaténation de strings) alors que 2 + 3 donne 5. Autre piège classique : la division par zéro renvoie 'Infinity' et une conversion échouée renvoie 'NaN' (Not a Number), qu'il faut tester avec isNaN(). Le mental model à retenir : une calculatrice = récupérer des données -> les nettoyer/convertir -> appliquer une opération selon un choix -> afficher le résultat. Les template literals (accents graves ` `) te permettront d'afficher proprement : `Le résultat de ${a} + ${b} est ${resultat}`. Mini-exemple : const a = Number('4'); const b = Number('5'); console.log(`Somme : ${a + b}`); // Somme : 9 Garde ces réflexes : convertir avant de calculer, vérifier les cas limites, et rester cohérent dans tes types. ÉNONCÉ DE L'ATELIER Ton objectif est de développer une mini-calculatrice fonctionnant entièrement dans la console. Le programme doit demander à l'utilisateur deux nombres, puis lui demander l'opération souhaitée (addition, soustraction, multiplication ou division), effectuer le calcul et afficher un résultat...
