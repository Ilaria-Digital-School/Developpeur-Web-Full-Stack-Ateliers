# Atelier : Coloriser les paragraphes avec classList

RAPPEL THÉORIQUE Dans le chapitre précédent, tu as appris à sélectionner des éléments du DOM avec des méthodes comme document.querySelector et document.querySelectorAll, puis à modifier leur contenu textuel. Nous allons maintenant nous concentrer sur la manipulation des classes CSS via la propriété classList. Chaque élément HTML possède un objet classList qui expose plusieurs méthodes essentielles : add('nom') pour ajouter une classe, remove('nom') pour la retirer, toggle('nom') pour l'ajouter si elle est absente ou la retirer si elle est présente, et contains('nom') qui renvoie un booléen indiquant si la classe est présente. Le mental model à retenir : ton JavaScript ne doit jamais écrire du style directement (évite element.style.color = 'red'). À la place, tu définis tes styles dans le CSS via des classes, et JavaScript se contente d'ajouter ou de retirer ces classes. C'est la séparation des responsabilités : le CSS gère l'apparence, le JS gère la logique. Erreurs fréquentes : confondre className (une chaîne complète qui écrase tout) et classList (un objet qui manipule les classes une à une) ; oublier que querySelectorAll renvoie une NodeList qu'il faut parcourir avec forEach ; passer le point ou le dièse à classList.add (on écrit add('rouge') et non add('.rouge')). Mini-exemple : const titre = document.querySelector('h1'); titre.classList.add('surligne'); titre.classList.toggle('actif'); En CSS : .surligne { background: yellow; } ÉNONCÉ DE L'ATELIER Ton objectif est de construire une petite page qui affiche plusieurs paragraphes et qui permet de les coloriser dynamiquement en manipulant uniquement leurs classes CSS grâce à classList.
