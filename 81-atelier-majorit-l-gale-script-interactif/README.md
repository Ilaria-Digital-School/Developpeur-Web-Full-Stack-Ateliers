# Atelier : majorité légale – script interactif

RAPPEL THÉORIQUE En JavaScript, une variable stocke une donnée réutilisable. Depuis ES6, on privilégie 'const' pour une valeur qui ne change pas et 'let' pour une valeur amenée à évoluer. Les types primitifs de base sont le nombre (number), la chaîne de caractères (string) et le booléen (boolean). Une notion essentielle ici : lorsqu'on demande une saisie à l'utilisateur (via prompt par exemple), la valeur récupérée est TOUJOURS une chaîne de caractères, même si l'utilisateur tape « 18 ». Il faut donc la convertir en nombre avec Number() ou parseInt() avant toute comparaison arithmétique. Le mental model à retenir : un programme lit une donnée, la transforme si nécessaire, puis prend une décision. La décision repose sur une condition (if/else) et des opérateurs de comparaison (>=, = 18) { ... } else { ... }`. Erreurs fréquentes : comparer une chaîne à un nombre sans conversion (« 17 » >= 18 peut donner un résultat trompeur), utiliser == au lieu de === (préférez toujours ===), ou oublier de gérer une saisie vide ou non numérique. Mini-exemple : ```js const saisie = prompt("Quel est votre âge ?"); const age = Number(saisie); if (age >= 18) { console.log("Vous êtes majeur."); } else { console.log("Vous êtes mineur."); } ``` ÉNONCÉ DE L'ATELIER Vous allez construire un script interactif qui détermine si un utilisateur est majeur ou mineur selon l'âge légal (18 ans). L'objectif est de mobiliser tout ce que vous avez vu jusqu'ici : déclaration de variables, types primitifs, conversion de types, opérateurs...
