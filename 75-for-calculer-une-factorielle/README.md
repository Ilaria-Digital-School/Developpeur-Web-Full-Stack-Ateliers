# For - Calculer une factorielle

RAPPEL THÉORIQUE Une boucle for permet de répéter un bloc de code un nombre déterminé de fois. C'est l'outil idéal quand on connaît à l'avance le nombre d'itérations. Le mental model à retenir : une boucle for parcourt une séquence de valeurs, et à chaque tour (itération), une variable de contrôle prend une nouvelle valeur. En Python, on écrit typiquement `for i in range(1, n+1):`, où `range(1, n+1)` génère les entiers de 1 jusqu'à n inclus. Attention : `range(a, b)` s'arrête à b-1, d'où le +1 fréquent. La factorielle d'un entier n, notée n!, est le produit de tous les entiers de 1 à n. Par exemple : 5! = 1 × 2 × 3 × 4 × 5 = 120. Par convention, 0! = 1. Le calcul se prête parfaitement à une boucle for : on part d'un accumulateur initialisé à 1, puis on le multiplie successivement par chaque entier. Mini-exemple : ```python resultat = 1 for i in range(1, 6): resultat = resultat * i print(resultat) # affiche 120 ``` Erreurs fréquentes : initialiser l'accumulateur à 0 (tout produit devient 0), oublier le +1 dans range (on saute la dernière valeur), ou confondre addition et multiplication. Vérifiez toujours vos bornes et l'état initial de vos variables. --- ÉNONCÉ DU WORKSHOP Votre mission est de développer un programme en Python (ou JavaScript si vous préférez) qui calcule la factorielle d'un nombre entier fourni par l'utilisateur, en utilisant exclusivement une boucle for.
