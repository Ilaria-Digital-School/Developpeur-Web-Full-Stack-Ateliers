# Construire une barre de navigation avec Flexbox

Rappel théorique : Flexbox et navigation Flexbox (Flexible Box Layout Module) est un modèle de mise en page CSS conçu pour répartir l'espace entre les éléments d'un conteneur, même lorsque leur taille est inconnue ou dynamique. Le modèle mental central consiste à transformer un conteneur parent en un contexte flex, contrôlant l'agencement de ses enfants selon un axe principal et un axe transversal. Les définitions clés incluent `display: flex;` pour créer le conteneur flex, `justify-content` pour aligner les éléments le long de l'axe principal (généralement horizontal), et `align-items` pour l'alignement sur l'axe transversal. La propriété `flex` combinée (comme `flex: 1;`) contrôle la répartition de l'espace disponible entre les éléments enfants. Une erreur fréquente est d'oublier que `justify-content` et `align-items` s'appliquent au conteneur, et non aux éléments enfants. Une autre erreur classique est de négliger la navigation sur mobile, qui nécessite souvent un empilement vertical (`flex-direction: column;`). Mini-exemple : un conteneur de navigation avec trois liens visés pour être alignés horizontalement et répartis sur toute la largeur. Le code commence par `.navbar { display: flex; justify-content: space-between; align-items: center; }`. L'espace restant est alors distribué autour des éléments enfants. Comprendre le projet et préparer son environnement Cet atelier vous invite à construire une barre de navigation (navbar) principale pour un site web, entièrement codée en HTML et CSS avec Flexbox. Vous allez reproduire un comportement moderne et responsive, similaire à celui des sites professionnels. Votre barre de navigation doit être intégrée à une page HTML simple.
