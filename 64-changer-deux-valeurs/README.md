# Échanger deux valeurs

**Rappel théorique** Une variable est un espace mémoire nommé qui stocke une valeur à un instant donné. Lorsqu'on parle d'« état », on parle de l'ensemble des valeurs contenues dans toutes les variables à un moment précis de l'exécution d'un algorithme. Échanger deux valeurs (swap) est l'une des opérations fondamentales en algorithmique : elle consiste à faire en sorte que la variable A contienne ce que contenait B, et vice versa. L'erreur classique du débutant est d'écrire directement A ← B puis B ← A. Ce faisant, la première instruction écrase la valeur initiale de A : quand on exécute B ← A, A contient déjà la valeur de B, donc rien n'a vraiment été échangé. Le mental model à retenir : imaginez deux verres, l'un contenant du lait, l'autre du jus. Pour les échanger, vous avez besoin d'un troisième verre vide (variable temporaire). Vous versez le lait dans le verre vide, vous versez le jus dans le verre à lait, puis vous versez le contenu du verre temporaire dans le verre à jus. Mini-exemple en pseudo-code : ``` A ← 10 B ← 25 tmp ← A A ← B B ← tmp // Résultat : A vaut 25, B vaut 10 ``` Cette logique s'applique dans de nombreux contextes réels : tri de tableaux, rotation d'éléments, gestion de files, etc. Maîtriser ce pattern, c'est poser une brique essentielle de votre culture algorithmique. --- **Énoncé du workshop** Dans cet atelier, vous allez concevoir et formaliser un algorithme permettant d'échanger...
