# Atelier : objet user et méthode présentation

RAPPEL THÉORIQUE Un objet littéral en JavaScript est une structure qui regroupe des données (les propriétés) et des comportements (les méthodes) sous un même nom. On le déclare avec des accolades, chaque paire étant composée d'une clé et d'une valeur : const user = { nom: 'Ada', age: 36 };. Une propriété stocke une donnée, tandis qu'une méthode est une fonction attachée à l'objet. Le mental model à retenir : un objet est une 'fiche' qui décrit une entité du monde réel (ici, un utilisateur) avec ses caractéristiques et ce qu'elle sait faire. À l'intérieur d'une méthode, le mot-clé this fait référence à l'objet lui-même. Il permet d'accéder aux propriétés du même objet : this.nom renvoie la valeur de la propriété nom. Attention, c'est une source d'erreurs fréquente : si vous écrivez une méthode avec une fonction fléchée (=>), this ne pointera PAS vers l'objet. Utilisez donc la syntaxe classique pour les méthodes qui ont besoin de this. Autres pièges courants : oublier les virgules entre les propriétés, ou tenter d'accéder à une clé inexistante (retourne undefined). Mini-exemple : const user = { prenom: 'Ada', age: 36, sePresenter() { return `Bonjour, je m'appelle ${this.prenom} et j'ai ${this.age} ans.`; } }; console.log(user.sePresenter()); Ce rappel fait le pont entre le cours sur les objets littéraux et cet atelier, où vous allez construire vos propres objets et méthodes. --- ÉNONCÉ DE L'ATELIER Vous allez créer et manipuler des objets représentant des utilisateurs.
