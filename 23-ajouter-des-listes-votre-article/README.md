# Ajouter des listes à votre article

Rappel théorique sur les listes HTML Vous avez déjà abordé les principes fondamentaux de l'HTML, y compris les balises et la structure minimale d'un document. Avant de commencer la mise en pratique, il est crucial de consolider les concepts propres aux listes. Trois types principaux existent : la liste non ordonnée (``) pour les éléments sans séquence particulière, la liste ordonnée (``) pour les étapes ou les séquences numérotées et la liste de définitions (``) pour associer des termes (``) et leurs descriptions (``). Le modèle mental à adopter est celui d'un emballage : une balise de conteneur (``, ``, ``) enveloppe des éléments (``, `/`) qui sont les unités de contenu. Les erreurs fréquentes incluent l'oubli de fermer les balises, la création de sauts inutiles entre les éléments de liste et la mauvaise imbrication. Une erreur classique est de placer directement du texte entre les balises `` et `` sans le passer par un ``. Un mini-exemple chiffré : pour lister trois ingrédients, vous utiliserez `` suivi de trois `` et vous fermerez avec ``. Chaque élément de liste peut contenir d'autres éléments HTML, y compris d'autres listes pour créer des structures imbriquées. Cette mise en pratique fait directement suite à votre travail sur les titres et les paragraphes. Vous allez maintenant intégrer ces listes dans un article existant pour structurer des informations et améliorer la sémantique de votre page.
