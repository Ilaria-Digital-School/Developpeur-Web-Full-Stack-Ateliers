# Créer, renommer et organiser des fichiers depuis l'éditeur

Rappel théorique : L'éditeur comme poste de pilotage Un éditeur de code, tel que Visual Studio Code, est l'outil principal d'un développeur pour interagir avec les fichiers et dossiers de ses projets. Contrairement à un gestionnaire de fichiers classique, l'éditeur offre une vue intégrée et des outils spécifiques pour manipuler l'arborescence directement depuis son interface. Les clés de cette manipulation sont la compréhension du « chemin » (path) et de l'« arborescence ». Le chemin est l'adresse unique d'un fichier ou dossier au sein du système. L'arborescence est la structure hiérarchique, comme un arbre à l'envers, où les dossiers contiennent d'autres dossiers ou fichiers. Un modèle mental efficace consiste à voir l'Explorateur de VS Code comme une carte interactive de votre projet. Les erreurs fréquentes incluent la création de fichiers au mauvais endroit, parce que l'on ne vérifie pas le dossier sélectionné, ou l'utilisation de noms avec des espaces ou caractères spéciaux, ce qui peut compliquer les références ultérieures en ligne de commande. Par exemple, pour un projet « mon_site », une arborescence logique serait : un dossier principal « mon_site » contenant un sous-dossier « css » pour les feuilles de style, un sous-dossier « js » pour les scripts, et un fichier « index.html » à la racine. Créer un fichier « style.css » directement dans le dossier « css » depuis l'éditeur est une opération fondamentale.
